Sync Apple Health with a Shortcut

A website isn't allowed to read Apple Health. Shortcuts is an Apple app that comes with every iPhone (icon: two overlapping coloured squares). It runs small recipes of steps called actions. You'll build one recipe that reads your daily Active Energy from Health and opens this app with those numbers. It takes about 10 minutes, once.

Your Health numbers travel in the part of the link after #. Browsers never send that part to a server, so the data stays on your phone.

What you're building

When finished, the shortcut looks like this (top to bottom):

Find Health Samples Active Energy · last 90 days · by day Repeat with Each (Health Samples) Get Details → Start Date Format Date → yyyy-MM-dd Get Details → Value (of Repeat Item) Text → Formatted Date:Value End Repeat Combine Text (separator ;) URL (link below + Combined Text) Open URLs

How adding actions works

  • At the bottom of the editor there's a Search Actions bar. Type an action's name and tap it to add it.
  • New actions are added at the bottom. To move one, press and hold it, then drag.
  • Blue words inside an action are settings: tap them to change them.
  • Coloured bubbles (for example Health Samples) are variables: the result of an earlier action. Each action automatically uses the result of the action right above it.

If your iPhone is set to German, the action names are in German. Search for the German name, or set the phone language to English while you build this; it keeps working afterwards.

Step by step

  1. Open Shortcuts, make sure you're on the Shortcuts tab, tap + (top right).
  2. Tap the name at the top (“New Shortcut”) → Rename → type Sync Burn.
  3. Search Find Health Samples and tap it. Then in that action:
    1. Tap the blue type (it may say Steps) → choose Active Energy.
    2. Tap Add Filter. Set it to Start Date · is in the last · 90 · days.
    3. Tap the small arrow / Show More on the action. Set Group By to Day, Sort by to Start Date (oldest first), and leave Limit off.
  4. Search Repeat with Each and tap it. It should read “Repeat with each item in Health Samples”, followed by an End Repeat line.
  5. Next come 4 actions that go between “Repeat with each” and “End Repeat”. If one lands below End Repeat, drag it up.
    1. Get Details of Health Sample → tap the blue detail → Start Date. Its input should be Repeat Item.
    2. Format Date → tap the date style → Custom → in the Format String field type exactly yyyy-MM-dd (small y, capital M, small d).
    3. Get Details of Health Sample again → detail Value. This one will wrongly point at Formatted Date: tap that bubble → Select Variable (or Repeat Item in the list) → pick Repeat Item.
    4. Text → tap inside the text box, clear it, then use the variable bar above the keyboard: insert Formatted Date, type a colon :, insert Health Sample Value. It should look like Formatted Date:Value with no spaces.
  6. Below End Repeat: search Combine Text. Its input should be Repeat Results. Tap New Lines → Custom → type ; (a semicolon).
  7. Search URL and tap the action called just “URL”. In its box paste this link:
    then, right after the =, insert the variable Combined Text.
  8. Search Open URLs and tap it. Its input should be URL.
  9. Tap Done, then tap the shortcut to run it. The first time, iPhone asks:
    • to let the shortcut read Health data → turn on Active Energy and allow;
    • to let it open a link → Always Allow.
    Safari opens Burn Goal and a message at the top says “Synced … days from Apple Health”. 🎉

Make it run by itself (optional)

  1. In Shortcuts, go to the Automation tab → + (or New Automation).
  2. Choose Time of Day, set e.g. 21:30, Daily, select Run Immediately, tap Next.
  3. Choose Sync Burn.

You can also run it any time from the Shortcuts app, a Home Screen widget, or by asking Siri “Sync Burn”. Running it again just refreshes the same days, so nothing is counted twice.

If something goes wrong

  • “Apple Health link had no readable days”: check that the Format String is exactly yyyy-MM-dd and that the Text has a colon between the two variables.
  • Numbers look about 4× too big: Health is counting in kJ. In the Health app go to Browse → Activity → Active Energy → scroll down → Unit → kcal (on some phones: Cal).
  • Nothing shows up for old days: the app only counts days between your goal's start date and goal date (tap Goal in the app to check them).
  • Synced in Safari but not in the Home Screen icon: use the app in Safari. A Home Screen icon keeps its own separate data.
